# Known-vector retrieval assets

These files are optional visual candidates. The vectorizer does not route by
filename, OCR result, or brand name: each asset must pass an affine/palette
match against the input, then beat the incumbent on perceptual fidelity,
source topology, and vector complexity.

- `mastercard_1996.svg` — Mastercard logo used from 1996–2016. Retrieved from
  [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:MasterCard_Logo.svg),
  where it is marked public-domain as a simple text/logo work. It remains a
  trademark; downstream use must respect applicable trademark law.
- `mastercard_early_1990s.svg` — earlier 1990–1996 variant, retained as an
  unregistered reference asset. Retrieved from
  [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:MasterCard_early_1990s_logo.svg)
  under the same public-domain text-logo notice and trademark caveat.
